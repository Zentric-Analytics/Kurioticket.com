# Stage 1 search diagnostics

This unit adds optional operational diagnostics; it does not change supplier identity, deadlines, inventory policy or protocol. Logs are one-line `[search:lifecycle]` JSON with schema version 1, product, first-party canonical request UUID, source, phase and monotonic elapsed duration. Only fixed categories/providers/platforms and finite counts/timings/sizes are admitted. No criteria, payloads, offer IDs, IPs, tracking IDs, credentials, signed cursors or session headers are accepted. Logging/clock failures are isolated from search execution.

Native request preparation, timer start/expiration/stop, caller cancellation, resolved fetch, body consumption/parsing and terminal categories are measured. Progressive hotel responses link the first-party client attempt UUID to the server's canonical search UUID without changing either identity. Validation counts and state publication are recorded by result controllers. List viewability records the first callback containing result rows, not a physically presented pixel frame. Actual device frame/bridge/body-transfer profiling remains part of authorized staging acceptance; `response-received` on RN means the fetch promise resolved and is not proof of first-header arrival. `response.json()` remains one combined body-consumption/parsing interval with no retained text copy.

Central routes preserve authorization and ownership, establish request-local AsyncLocalStorage context for cache queue/publication timing, and measure single-pass public response serialization. Registry provider timings distinguish skipped, empty, partial, failed and successful inventory. Existing KAYAK initial/poll/page diagnostics remain in place. Cohort encoding, normalization and flight deduplication add bounded numeric measurements. Response-layer byte sizes must not be confused with proxy compressed transfer bytes.

Tests cover sensitive-field exclusion, logging outage, concurrent request isolation, complete JSON contract preservation, canonical correlation and stable viewability reporting. Existing admission, history, ownership and navigation tests retain their assertions while recognizing the new diagnostic adapters. Rollback is a scoped revert of this unit; no migration or setting changes are required. Native changes require confirmed Preview update activation after owner-authorized delivery. No integration or deployment is authorized by this document.

Each event names its measurement span. elapsedMs is local to that span; durationMs measures the named operation. Do not subtract elapsed values across different spans, clocks or devices, or add concurrently executing supplier durations. Stage 2 uses these boundaries to establish the coordinated total budget.
