## Image strategy

- Paris additions use the approved local Paris destination fallback.
- New York additions use the approved local New York destination fallback.
- Tokyo additions use the approved local neutral hotel fallback because the repository has no local Tokyo destination asset suitable for primary related-hotel cards.
- No remote image, hotel-site image or booking-provider image is used.

## Follow-up image risk

The pre-existing ten-image rotated details gallery includes generic cross-product repository artwork after the truthful primary image. This expansion does not broaden that legacy behavior or mislabel those images as property photography. A later licensed-gallery project should replace unrelated generic gallery candidates without blocking the production-safe primary images required for related cards.
