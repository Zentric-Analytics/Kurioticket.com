# Static car fixture provenance

This catalogue is a deterministic Kurioticket comparison fixture, not live availability. Passenger, door, transmission and air-conditioning values describe the represented configuration. `bags` is a conservative Kurioticket rental-comparison normalization informed by cargo volume and rental-class convention, not a manufacturer bag specification. Prices, cancellation, payment, mileage allowance, fuel policy, deposits, excess, minimum rental age, pickup terms and offer terms are generated fixture policy.
